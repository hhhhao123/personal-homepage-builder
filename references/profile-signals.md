# Profile Signals

Use profile signals to help users express themselves. Never treat them as deterministic rules.

## Signal Types

### Professional Signals

Examples: researcher, teacher, engineer, designer, founder, creator, consultant, doctor, lawyer, artist, student.

Use for:
- audience expectations
- credibility needs
- content priority
- tone constraints

Do not assume every person in a profession wants the same site.

### Personality Signals

Examples: MBTI, enneagram, introvert/extrovert, calm/energetic, analytical/expressive, structured/freeform.

Use for:
- interaction density
- motion level
- copy tone
- page rhythm

Ask:
- Which parts of this label feel true?
- Which parts feel wrong or stereotyped?
- Should the site show this directly, subtly, or not at all?

### Cultural And Taste Signals

Examples: music, films, books, games, fashion, architecture, favorite apps, favorite places, favorite colors.

Use for:
- memory point
- image direction
- texture/material choices
- naming and section atmosphere

Rule: one or two signals should become design accents; not every favorite thing needs to appear.

### Zodiac Or Symbolic Signals

Examples: zodiac sign, birth season, element, lucky color, personal symbols.

Use for:
- optional metaphor
- subtle visual motifs
- color or seasonal atmosphere

Do not make astrological claims. Phrase as "symbolic inspiration" or "personal motif".

## Confidence Tags

Tag each signal in the brief:

- `strong`: user explicitly cares about it and wants it represented.
- `medium`: useful clue, but representation should be subtle.
- `weak`: only an exploratory clue.
- `avoid`: user mentioned it but does not want it reflected.

## Good Translation Examples

- MBTI `INTJ`, user says "I like structure and quiet": use clear systems, restrained motion, precise hierarchy.
- Leo zodiac, user says "I like the confident part but not flashy": use one bold hero statement, not gold-heavy luxury styling.
- R&B listener, academic researcher: use night studio atmosphere as a memory point while keeping research content primary.
- Food blogger who loves handwritten notes: use editorial layout, warm paper texture, recipe/archive structure.

## Bad Translation Examples

- "You are Gemini, so the site must be split-color and chaotic."
- "INTP means dark terminal theme."
- "Artist means maximalist portfolio."
- "Consultant means corporate blue SaaS landing page."
